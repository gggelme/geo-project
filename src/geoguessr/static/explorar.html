Falta la API key de Google

El explorador usa Google Street View (la misma fuente que el dataset). Para activarlo:

  1. En Google Cloud Console, creá un proyecto y habilitá Maps JavaScript API y Street View Static API.
  2. Creá una API key (conviene restringirla a esas dos APIs y a http://127.0.0.1:*).
  3. Agregá esta línea al .env de la raíz del repo:
    GOOGLE_MAPS_API_KEY=tu_key
  4. Reiniciá el servidor y recargá esta página.
Vistas para el modelo
Cómo funciona

Cuando capturás, el servidor baja de la Street View Static API las 4 vistas del panorama (512×512, FOV 90°, mirando al N, E, S y O, igual que en el dataset), les aplica la misma recompresión que en el entrenamiento y se las pasa a la ResNet-18. La predicción es la celda con más probabilidad promediando las 4 vistas.

Tip: el globo sigue funcionando para saltar a otro lugar cuando quieras.
